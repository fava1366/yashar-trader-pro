# Yashar Trader Pro (Android) v1.8

نسخه حرفه‌ای اسکنر الگوی بازار طلا و فارکس با سبک نمودار MetaTrader.

## ویژگی‌ها
- نمودار کندل واقعی از Twelve Data (سبک متاتریدر: محور قیمت راست، خط قیمت فعلی، زوم و پن)
- نمایش قیمت لحظه‌ای خرید (Ask) و فروش (Bid) روی نمودار و در باکس جداگانه
- خطوط حمایت (سبز) و مقاومت (قرمز) از سقف/کف محلی
- آلارم صوتی + گفتار فارسی وقتی قیمت نزدیک کف یا سقف باشد
- تأیید چندتایم‌فریمی M3 + M5 + M15
- حالت زنده: به‌روزرسانی کندل و قیمت لحظه‌ای

## ساخت APK با GitHub Actions
1. این مخزن را در GitHub بسازید و فایل‌ها را آپلود کنید.
2. از تب Actions، workflow **Build Android APK** را اجرا کنید.
3. فایل APK دیباگ را از Artifacts دانلود کنید.

## نکات
- نیاز به API Key رایگان یا پولی از [Twelve Data](https://twelvedata.com)
- بدون اتصال به حساب معاملاتی و بدون اجرای معامله
- برنامه‌نویس: یاشار صالحی
